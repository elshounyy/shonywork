READY TO UPLOAD TO GITHUB PAGES
1. On github.com click New repository. Name it: portfolio (any name works). Keep it Public. Create.
2. Unzip this file. Open the repo, click "uploading an existing file", drag EVERYTHING inside the unzipped folder
   (index.html, favicon.svg, .nojekyll, images, fonts) into the page, then click Commit changes.
   Tip: if .nojekyll is hidden on your computer it is fine, the site works without it.
3. Repo Settings > Pages > Source: Deploy from a branch > Branch: main, folder / (root) > Save.
4. After about a minute the site is live at https://YOUR-USERNAME.github.io/portfolio/
   (Name the repo YOUR-USERNAME.github.io to get https://YOUR-USERNAME.github.io/ directly.)
Needs internet to load the Google fonts (Pirata One, Pinyon Script, Space Mono); everything else is included.
