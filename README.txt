Deploy on GitHub Pages
1. Create a new repo on GitHub (example: portfolio).
2. Upload everything in this folder (index.html, images/, fonts/) to the repo root.
3. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main > folder: / (root) > Save.
4. After about a minute the site is live at https://YOUR-USERNAME.github.io/portfolio/
Fonts: titles use Pirata One (Google Fonts, loads automatically online) with a scratched-texture mask; body uses Poppins.
